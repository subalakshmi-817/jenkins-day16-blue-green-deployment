============================================================
2. WHAT IS BLUE-GREEN DEPLOYMENT?
============================================================

Blue-Green Deployment is a deployment strategy where two
environments are maintained.

BLUE:
Current stable application.

GREEN:
New application version.

Example:

Blue  = Version 1.0
Green = Version 2.0

Version 2.0 is first deployed to Green.

After successful testing:

Green becomes production.

If Green fails:

Blue remains available.

This provides a safer deployment and easier rollback.

============================================================
3. WHY BLUE-GREEN DEPLOYMENT?
============================================================

Traditional deployment can cause downtime.

Example:

Stop old application
        ↓
Deploy new application
        ↓
Start new application

During this period, users may experience downtime.

Blue-Green Deployment avoids this problem by maintaining
two environments.

Blue continues running while Green is prepared.
